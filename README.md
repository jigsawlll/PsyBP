# PsyBPLLM: A Baseline Psychological Counseling Large Language Model

![Status](https://img.shields.io/badge/Status-Under%20Review-orange)

## 📖 Overview
**PsyBPLLM** is a 7B-parameter large language model specifically fine-tuned for psychological counseling scenarios. It is built upon the Qwen2.5-7B architecture and fine-tuned using the **PsyBP dataset**, a high-quality, process-standardized multi-turn dialogue corpus.

This repository serves as the official model and codebase placeholder. Currently, PsyBPLLM acts as the core baseline model for evaluating the **CARE (Counseling Adaptive Reasoning and Enhancement)** framework. 

## ✨ Key Features
* **Process-Standardized:** Unlike general emotional support models, PsyBPLLM's training data is structured around a rigorous 6-stage counseling dialogue framework.
* **Theory-Grounded:** Integrates multi-paradigm psychological methodologies, including Single-Session Counseling, Structured Association Technique (SAT), and Acceptance and Commitment Therapy (ACT).
* **Strong Empathic Reasoning:** Capable of executing deep emotional resonance and providing insightful, solution-oriented guidance.
